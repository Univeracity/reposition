# Reposition identity

The logo stands alone. The full **REPOSITION** wordmark is a separate graphic,
including its own R. Compositions place the two together with clear space.

| Asset | Use |
| --- | --- |
| [README header](reposition-readme-header.png) | Selected horizontal layout, 1280 × 400 |
| [Social preview](reposition-social.png) | Selected centered layout, 1280 × 640 |
| [Glass logo](reposition-logo-glass.png) | Standalone transparent raster logo |
| [Flat logo](reposition-logo-flat.svg) | Standalone vector mark for small sizes |
| [Wordmark](reposition-wordmark.svg) | Standalone outlined uppercase name |

Editable SVG versions of the [header](reposition-readme-header.svg) and
[social preview](reposition-social.svg) are included. They embed the glass logo
and use paths for lettering, so viewing them needs no installed font.

The glass logo was created with image generation from a selected concept.
The flat logo and custom wordmark were drawn as original vector artwork based
on the pane geometry. Supporting copy in the compositions uses DejaVu Sans;
its [license notice](../../licenses/DejaVu-Bitstream-Vera.txt) is retained.
See the project's [LICENSE](../../LICENSE) and [NOTICE](../../NOTICE).

To configure GitHub's social preview, upload **reposition-social.png** in the
repository's settings. It is under 1 MB at GitHub's recommended 1280 × 640 size.
See [GitHub's instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
